# Contributing to OmniOps

## Branch Naming Convention
All branches must include the associated Jira ticket ID using the following format:
`type/JIRA-KEY-NUMBER`

**Valid Types:**
* `feat/`: New features
* `fix/`: Bug fixes
* `chore/`: Maintenance, dependencies, or configuration changes

**Examples:** * `fix/BAD-37`
* `feat/BAD-42`

## Pull Request Process
1. Ensure your branch is up to date with `main`.
2. Open a Pull Request using the default template.
3. A minimum of one peer approval is required before merging.
4. All automated status checks (e.g., SonarQube) must pass.
