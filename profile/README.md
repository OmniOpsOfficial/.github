# OmniOps Engineering

Welcome to the official GitHub organization for OmniOps. 

## Organization Structure
Our engineering organization operates on a Chapter-based model. Access is strictly provisioned via delegated project-based GitHub Teams.

## Engineering Standards
All OmniOps repositories enforce strict CI/CD and integration standards:
* **Jira Integration:** All branches and commits must reference the assigned Jira ticket (e.g., `fix/BAD-37`).
* **Branch Protection:** Direct commits to `main` are blocked globally. All code requires automated testing validation and peer review prior to merging.
* **Guidelines:** Review our global [Contributing Guidelines](https://github.com/OmniOpsOfficial/.github/blob/main/CONTRIBUTING.md) before submitting a Pull Request.

## Security and Vulnerability Disclosure
Please review our [Security Policy](https://github.com/OmniOpsOfficial/.github/blob/main/SECURITY.md) for instructions on how to securely disclose vulnerabilities to the OmniOps security team.
