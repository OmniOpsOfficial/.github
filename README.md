# OmniOps Organization Defaults

This repository stores the global configuration files for OmniOps. These files establish the baseline security and contribution rules for all engineering projects.

## Included Configurations

* Pull request templates
* Issue reporting templates
* Security vulnerability policies
* General contribution guidelines

## Implementation

These configurations are applied across the organization in two ways:

1. **New Projects:** The approved language boilerplates bundle these baseline files. Creating a repository from those boilerplates ensures immediate compliance.
2. **Existing Projects:** A synchronization workflow automatically pushes file updates from this repository directly to active codebases.
